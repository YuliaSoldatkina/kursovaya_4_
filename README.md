# Сервис управления рассылками

Веб-приложение на Django для управления email-рассылками, клиентами, сообщениями и статистикой отправок.

## Возможности

- Регистрация пользователей с подтверждением email.
- Вход и выход из системы.
- Восстановление пароля.
- Управление получателями рассылок: создание, просмотр, редактирование и удаление.
- Управление сообщениями: создание, просмотр, редактирование и удаление.
- Управление рассылками: создание, просмотр, редактирование и удаление.
- Динамический статус рассылки: «Создана», «Запущена», «Завершена».
- Валидация дат начала и окончания рассылки.
- Ручной запуск рассылки.
- Отправка писем каждому получателю рассылки.
- Сохранение попыток отправки со статусом и ответом сервера.
- Статистика по рассылкам и попыткам отправки.
- Ограничение доступа: пользователь работает только со своими данными.
- Роль менеджера: просмотр всех клиентов и рассылок.
- Серверное и клиентское кеширование.

## Технологии

## Запуск проекта

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

```bash
pip install django
```

3. Выполните миграции:

```bash
python manage.py migrate
```

4. Создайте суперпользователя:

```bash
python manage.py createsuperuser
```

5. Запустите сервер:

```bash
python manage.py runserver
```

6. Откройте в браузере:

```text
http://127.0.0.1:8000/
```

## Административная панель

Админка доступна по адресу:

```text
http://127.0.0.1:8000/admin/
```

## Роли пользователей

### Пользователь

- Создаёт, просматривает, редактирует и удаляет своих клиентов.
- Создаёт, просматривает, редактирует и удаляет свои сообщения.
- Создаёт, просматривает, редактирует и удаляет свои рассылки.
- Запускает свои рассылки.
- Просматривает свою статистику.

### Менеджер

- Просматривает всех клиентов и все рассылки.
- Не редактирует и не удаляет чужие данные.
